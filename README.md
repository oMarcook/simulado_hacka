#  Planejamento Financeiro para Jovens Adultos

MVP desenvolvido para o desafio de melhorar a experiência financeira de jovens adultos.

## O problema

Muitos jovens têm dificuldade para entender seus gastos, estabelecer metas e perceber como pequenas decisões afetam seu orçamento. Informações financeiras complexas tornam esse controle ainda mais difícil.

## solução

Uma aplicação que transforma os dados financeiros em informações simples e visuais, ajudando o usuário a responder:

- Para onde meu dinheiro está indo?
- Quanto ainda posso gastar considerando minhas contas e minha meta?
- Como uma compra afetaria meu planejamento?

A experiência reúne um resumo mensal, um simulador de gastos e um aviso antes do pagamento. O usuário pode avaliar o impacto da compra e decidir se deseja continuar ou ajustar o valor.

## Diferencial

Além de mostrar o que já aconteceu, o aplicativo ajuda a avaliar
uma decisão antes que ela vire um gasto.

## Personalização no MVP

Os cálculos consideram o saldo, as contas previstas, a fatura e a
meta registrada no banco da conta de demonstração.

A definição de objetivos e a edição da meta pelo próprio usuário
são próximos passos do projeto.
